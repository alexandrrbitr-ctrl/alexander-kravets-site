FAQ

Частые вопросы

Какие данные нужны?

Зависит от вопроса. Обычно достаточно ID сделки/клиента, дат, стадий, сумм, менеджера, результата и нескольких сегментирующих признаков.

Можно обезличить клиентов?

Да. Для большинства коммерческих задач имя, телефон и другие персональные данные не нужны.

Обязательно использовать SQL?

Нет. Инструмент выбирается под объём и структуру данных. Для многих задач достаточно корректной выгрузки и табличной аналитики.

Можно сделать только один конкретный расчёт?

Да. Формат не обязан быть большим аудитом: можно разобрать одну воронку, базу, менеджеров или отдельную гипотезу.
