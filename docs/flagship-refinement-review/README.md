# Упаковка флагмана и компактные служебные страницы

Ветка `feature-flagship-service-refinement` создана от актуальной `main`, коммит `b1429198f39e251f1b269fe4938cfbada2597fe1`. Изменения предназначены для проверки; в `main` не объединены и через GitHub Pages не опубликованы.

## Выполненные изменения

1. **Флагман «Построение отдела продаж под ключ».** На странице `/sales-department-from-scratch/` уточнены организация запуска, коммерческая модель, Bitrix24, телефония, интеграции, подбор и адаптация, KPI и управленческий контроль. Разделены личная коммерческая работа и технические работы профильных специалистов. До старта согласуются границы ответственности, доступы, лицензии и сервисы, критерии приёмки, срок и объём сопровождения. Сохранён вариант проектирования без внедрения. Кнопка «Обсудить запуск отдела» открывает существующее окно мессенджеров.
2. **Согласованность описаний.** Обновлены только краткое представление флагмана на главной и его первое направление в каталоге. Остальные шесть направлений, навигация по семи направлениям и контакты сохранены.
3. **Подтверждённый опыт.** Сохранён существующий кейс удалённого отдела: 5 менеджеров, 33 договора в первый месяц, 134% / 150% плана. Новые технические работы не приписаны этому кейсу. Все пять страниц кейсов побайтно совпадают с исходным коммитом. Графики, диаграммы, SVG, иллюстрации и новые блоки визуализации кейсов не создавались.
4. **Политика.** Изменён только существующий блок CSS юридического документа: уменьшены шрифты, ширина колонки и интервалы. Содержание `privacy.html`, якорь `#cookies`, старый адрес `cookies.html`, код согласия и пустые ID аналитики сохранены.
5. **Обо мне.** Удалена отдельная подробная секция образования с датами, вузом, специальностью и названием учебной платформы. В разделе компетенций оставлен один короткий абзац о медицинском образовании и подготовке по бизнес-аналитике. Остальная страница сохранена.

- 1658 внутренних ссылок и ресурсов без ошибок; 57 корректных блоков JSON-LD; sitemap по-прежнему содержит 54 URL.
- HEAD, canonical, метаданные и JSON-LD всех страниц сохранены; футеры, контакты и навигация сохранены.
- `privacy.html`, `cookies.html`, `site.js`, `analytics-config.js`, `styles.css`, `services/packaging.css`, sitemap, llms.txt и архитектурный документ не изменены.
- Семь сценариев согласия: отключённая аналитика, отказ и перезагрузка, принятие и отзыв, сохранённое согласие, некорректная запись, блокировка localStorage, отзыв в другой вкладке. Использовался тестовый ID с перехватом внешних запросов; реальные данные не передавались и аналитика не подключалась.
- `node --check site.js` и `git diff --check` прошли.
