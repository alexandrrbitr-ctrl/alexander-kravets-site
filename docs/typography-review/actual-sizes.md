# Фактические размеры после ревизии

Источник — `getComputedStyle()`, `getBoundingClientRect()` и высота документа в Microsoft Edge, zoom 100%, DPR 1. Это измерения браузера после загрузки CSS; значения округлены до 0,01 px. Все 285 сочетаний страницы и ширины: [actual-sizes.csv](actual-sizes.csv).

Заголовки H1–H3 проверены на всех 57 страницах. Подчинённая бронзовая строка H1 каталога сохраняет прежнее отношение 0,78 к заголовку. Смешанные подтверждения под первым экраном главной («с 2012 года» и показатели) остаются компактными: 28 px desktop / 25 px mobile. Встроенные цифры каталога кейсов и профиля сохраняют меньший размер (20–28 px в зависимости от шаблона и ширины); им не требуется масштаб главных результатов 42/34 px. Подписи к основным показателям — 13–14 px. Короткие номера навигации и фирменная подпись в шапке сохраняют меньший служебный размер. Шапка и окно мессенджеров используют утверждённые размеры интерфейса.

Обычная секция: по 56 px desktop и по 40 px mobile; уменьшенные служебные секции и строки каталога используют отдельный ритм. Нулевой padding снизу у hero сохраняет существующую композицию с карточками.
