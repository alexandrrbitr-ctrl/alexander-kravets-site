## Рабочая версия инструмента

- `/tools/sales-economics/` — полноценный локальный калькулятор из предоставленного архива. `/tools/` — каталог с одним готовым инструментом. Пустые продукты не создавались.
- Общая серебряная эмблема, шапка, подвал, меню, активный раздел «Инструменты» и плавающий выбор мессенджеров.
- Сохранены формулы сделок, выручки, валовой прибыли, расходов, результата, маркетинга на сделку, безубыточности и сценария роста конверсии.
- Условный исходный пример: 40 сделок, 2 млн ₽ выручки, 700 тыс. ₽ валовой прибыли, 650 тыс. ₽ расходов, 50 тыс. ₽ результата. Маркетинг на сделку — 6250 ₽, безубыточность — 929 лидов. При росте с 4% до 5% результат 225 тыс. ₽, изменение +175 тыс. ₽. Эти цифры — учебная модель, не клиентский кейс.
- Исправлен пограничный эффект двоичного округления при расчёте целого числа лидов: сумма 0.1 + 0.2 не должна добавлять лишний лид. Ограничение конверсии 100% явно объясняется при моделировании.
- Входные данные проверяются; предусмотрены нули, недостижимая безубыточность, дробное ожидаемое число сделок, возврат примера и очистка. Подписи объясняют маржу, период и процентные пункты.
- «Обсудить результаты» открывает общий выбор мессенджеров. В ссылку или сообщение финансовые значения не добавляются. Номер и никнеймы текстом не выводятся.

## Приватность

Расчёты выполняются отдельными локальными ES-модулями без зависимостей. Нет fetch, отправки формы, сохранения показателей в URL, localStorage или sessionStorage. Поля расположены вне формы: Enter не отправляет данные даже без JavaScript.

Страница не загружает analytics-config.js. Дополнительный флаг data-private-tool выключает общий загрузчик аналитики независимо от настройки счётчиков. В браузерном тесте счётчики принудительно заданы: при заполнении полей, изменении сценария, Enter и открытии окна связи сетевых запросов не возникло; URL и хранилища не изменились. Сообщения третьим лицам не отправлялись.
