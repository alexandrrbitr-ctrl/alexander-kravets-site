## WhatsApp: короткая ссылка без номера в HTML

Рекомендуемый вариант — официальная короткая ссылка WhatsApp Business, скопированная из аккаунта владельца: «Инструменты → Короткая ссылка». Подходит адрес вида `https://wa.me/message/<код>`, созданный самим WhatsApp. Его нельзя придумать или получить только из номера телефона.

[Официальная инструкция WhatsApp](https://faq.whatsapp.com/502291734918768) описывает создание и копирование ссылки в приложении. Для подключения нужна фактическая ссылка из аккаунта, которую можно проверить перед заменой всех адресов WhatsApp в HTML, site.js, llms.txt и документации.

Пока короткая ссылка не предоставлена, эта ветка сохраняет работающий прямой чат. Его URL содержит номер и доступен в исходном HTML и JavaScript. Никакой маскировки или ложного заявления о защите номера нет.

Короткая ссылка уберёт номер из публичной разметки сайта, но не гарантирует его секретность: получатель ссылки может перейти в WhatsApp и увидеть данные аккаунта. Это уменьшение прямой экспозиции номера на сайте, а не защита от установления номера.

Не подключены сторонние сокращатели, платные сервисы, новые API или трекинг. Редирект на GitHub Pages через HTML/JavaScript также не скрыл бы номер: адрес назначения остался бы публичным.
