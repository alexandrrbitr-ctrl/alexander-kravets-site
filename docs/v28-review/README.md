- Личный Telegram: @Alekdvv. Канал @formularosta_pro подписан отдельно. MAX ведёт только в канал; личный чат MAX не опубликован.
- Номер WhatsApp не выводится в тексте, aria-label или JSON-LD. Прямая ссылка пока сохраняет номер в исходном коде. [Предложение короткой ссылки и границы приватности](contacts.md).
- Контакты обновлены на всех 57 HTML-страницах, в llms.txt и Person.sameAs. Остальные SEO-данные, sitemap, подтверждённое содержание, иллюстрации и архитектура будущих разделов сохранены.

## Выполненные проверки

17 октября 2026 года; локальный статический сервер, Chromium / Microsoft Edge headless.

- 57 страниц × 5 размеров: 360, 390, 430, 768 и 1440 px — 285 проверок отображения, без ошибок JavaScript, недоступных ресурсов и горизонтальной прокрутки. Видимого номера, ссылок tel: и опубликованного личного MAX нет.
- 434 открытия окна, включая 216 из мобильного меню: корректные ссылки, aria-expanded, видимость окна, отсутствие перекрытий текста/изображений/кнопок, Escape и возврат фокуса.
- Проверка расчётного контраста текста: нарушений порогов 4.5:1 для обычного и 3:1 для крупного текста не обнаружено.
- Мобильная навигация на 54 страницах: aria-expanded, focus trap, Escape, снятие блокировки прокрутки, переход к кейсам и активный пункт.
- 73 раскрывающихся блока FAQ / деталей — Enter и Space.
- 6 сценариев конфигурации MAX: пустое значение, канал, неверный протокол, чужой домен и неподтверждённый профиль не становятся личной кнопкой; подтверждённый тестовый профиль становится. Тестовые значения не записывались в сайт.
- 14 дополнительных проверок общего компонента: Space, кнопка закрытия, клавиатура, переход в каждый из трёх мессенджеров, закрытие меню при переходе на desktop, fallback без JavaScript. Для проверки открытия вкладок внешние ответы подменялись локальными тестовыми страницами; реальная доступность ссылок проверена отдельно HTTP-запросами, см. contacts.md. Сообщения не отправлялись.
- 1710 внутренних ссылок, якорей и ресурсов — все назначения найдены. 59 блоков JSON-LD корректно разбираются; изменён только Telegram в контактном sameAs.
- 1424 исходных абзаца и элемента списков сохранены, кроме необходимых исправлений контактов. Sitemap содержит прежние 54 URL.
