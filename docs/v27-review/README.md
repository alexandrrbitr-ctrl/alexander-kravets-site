Ветка: `design-v27-premium`. Скриншоты отражают состояние сайта в этом коммите. Материалы финальной версии V27 для публикации.

Мобильная панель Telegram/WhatsApp переведена в обычный поток: фото, текст и интерфейс не перекрываются. Длинные снимки браузера фиксируют sticky header один раз; для проверки меню учитывайте также снимки первого экрана.

## Проверки этапа

- 57 страниц × 5 ширин (360, 390, 430, 768, 1440 px): 285 сочетаний, без горизонтальной прокрутки, видимого телефона и ошибок JavaScript/HTTP/console.
- 54 существующих мобильных меню: размещение в body, Escape, блокировка прокрутки, focus trap, переходы и активный пункт.
- 73 раскрывающихся блока проверены клавишами Enter и пробел.
- Личная кнопка MAX скрыта; шесть сценариев конфигурации проверяют, в том числе, отказ для канала и неподтверждённого профиля.
- Telegram, WhatsApp и канал MAX возвращают HTTP 200 (WhatsApp через перенаправление).
- Проверены внутренние ссылки, один H1, alt, HTML-вложенность, JSON-LD, SEO и сохранность содержательных абзацев и пунктов. Sitemap сохраняет 54 URL.
- Выполнены node --check site.js и git diff --check.

Контраст рассчитан для видимого текста: 4.5:1 для обычного и 3:1 для крупного. Это не полный аудит доступности.
