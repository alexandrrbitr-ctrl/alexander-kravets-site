# Компактная политика конфиденциальности

Ветка `design-compact-typography`, отдельное дополнение к ревизии типографики. В `main` не объединено, живая версия сайта не изменена.

## Изменения

- `privacy.html` — один документ в узкой колонке, без коммерческого первого экрана. Раздел cookies и аналитики расположен по якорю `#cookies`.
- `cookies.html` — совместимый старый адрес: `location.replace` и meta refresh ведут к `privacy.html#cookies`; в HTML остаётся доступная резервная ссылка. На статическом GitHub Pages это ответ 200 с перенаправлением в браузере, а не серверный HTTP 301.
- Все 57 футеров содержат одну ссылку «Политика конфиденциальности». Отдельная ссылка Cookies удалена. Кнопка изменения согласия остаётся и показывается при настроенном счётчике; на самой политике предусмотрена такая же кнопка.
- `premium.css` — небольшая область стилей только для юридического документа. H1 28 px, H2 20 px, текст 16 px, колонка не шире 72ch. Коммерческие шаблоны не менялись.
- `site.js` — ссылка из уведомления ведёт на новый раздел; исправлены отзыв согласия и обработка отказа в другой вкладке. При недоступном localStorage выбор действует на открытой странице. Код мессенджеров и навигации не изменялся.
- Идентификаторы Яндекс Метрики и Cloudflare остались пустыми. Реальные сервисы не подключались.

## Проверки

Все 57 HTML-страниц проверены на 360, 390, 1280, 1440 и 1920 px — 285 открытий и HTTP-проверок ссылки на политику. Горизонтальной прокрутки, ошибок JavaScript, видимого номера телефона и старой ссылки Cookies в футере не обнаружено. Подтверждены размеры документа 28 / 20 / 16 px; ширина колонки на desktop 621 px. Старый адрес проверен с JavaScript и без него.

Семь сценариев согласия проверены с тестовым ID и перехваченным скриптом: отключённая аналитика; отказ и перезагрузка; согласие и отзыв; сохранённое согласие; некорректная запись; запрет localStorage; отзыв в другой вкладке. Внешние запросы перехватывались, реальные данные в Метрику не передавались.

Статическая проверка: 1658 внутренних ссылок и ресурсов без ошибок, 57 корректных блоков JSON-LD, прежние 54 URL в sitemap. Содержимое и SEO коммерческих страниц до футера побайтно сохранены относительно `dddc0f5`. `node --check site.js` и `git diff --check` — успешно.
