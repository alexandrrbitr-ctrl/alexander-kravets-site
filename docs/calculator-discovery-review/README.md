# Видимый вход в бесплатный калькулятор

Ветка `feature-calculator-discovery`, база — актуальная `feature-case-charts-and-sales-economics` / `ccdb624ad831fc6841591bc657671e29f8b308e0`.

Архив прочитан и распакован вне репозитория. Применён `apply_promo.py`, предыдущие графики, калькулятор и реквизиты ИП повторно не устанавливались. В `main` не объединено, GitHub Pages не публиковался.

## Изменения

- `index.html`: один компактный блок перед секцией «Обо мне».
- `services/index.html`: такой же блок перед «Обсудить задачу».
- `tools-promo.css`: изолированные стили только `.fr-tools-promo*`.

«Открыть калькулятор» ведёт на существующий `/tools/sales-economics/`, «Все инструменты» — на `/tools/`. На вложенной странице услуг сохранены правильные относительные пути `../tools/...`. Маркер `data-goal="sales_calculator_open"` предназначен для возможного будущего события; аналитика этим патчем не включалась.

## Исправления по результатам проверки реального сайта

Демонстрационные картинки из архива не использовались как подтверждение отображения сайта. На полных страницах общая типографика перебивала шрифт подписи «Бесплатный инструмент»: получалось 16–17 px. Селектор уточнён только в новом CSS, подпись приведена к читаемым компактным 13 px. Ссылка «Все инструменты» получила `display:inline-flex`, выравнивание по центру и минимальную высоту 44 px для удобного нажатия. Основная CTA также не ниже 44 px.

Общие CSS/JS не редактировались. Временная копия установщика вне репозитория синхронизирована с этими двумя CSS-исправлениями, чтобы её повторное применение и строгая проверка `--check` проверяли финальный вариант. Исходная архивная версия `--check` также успешно отработала сразу после первоначального применения, до указанных исправлений.
