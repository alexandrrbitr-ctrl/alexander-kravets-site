## Изменения

- Общая панель: «Мы используем cookie для улучшения работы сайта и анализа посещаемости. Подробнее». Ссылка «Подробнее» ведёт в `privacy.html#cookies` с любой глубины URL.
- Кнопки «Только необходимые» и «Принять» доступны сразу. Светлая панель, тёмный текст 13 px, без заголовка и декоративных иконок. Отказ расположен первым и не требует дополнительных действий.
- На компьютере текст и кнопки расположены горизонтально; на телефоне кнопки остаются рядом под текстом. Существующий механизм размещения плавающих контактов учитывает размеры панели. При открытом мобильном меню панель скрывается до его закрытия.
- `site.js`: изменена только строка разметки уведомления; вся логика согласия идентична базе. Счётчик 113697096, ключ/версия записи и срок 180 дней сохранены. Сохранённое разрешение включает просмотры последующих страниц/визитов; отказ отключает необязательную аналитику. Изменить выбор можно через существующую кнопку в подвале.
- `privacy.html`: только замена названий двух кнопок в существующем описании. Остальные тексты, SEO, формулы и интерфейс калькулятора не менялись.

### Известный сбой общего preflight

Аудитор по-прежнему выдаёт 7 ошибок из-за существующего файла подтверждения Google `google702c29dfb69c29e5.html`: требует title, H1, canonical, description, реквизиты и включение в sitemap. Это служебный файл с точным содержимым подтверждения. Файл и аудитор не изменены. Эти ошибки были в базовой main; новых ошибок ссылок/JSON-LD не обнаружено. Общий preflight и соответствующий CI нельзя считать успешными.

Проверено 60 HTML-файлов статическим аудитором, из них 58 страниц интерфейса браузером; остальные два — служебные Google verification и перенаправление cookies. Сохранены 56 URL sitemap и 59 блоков JSON-LD. 59 HTML-файлов побайтно после нормализации перевода строк совпадают с базой, политика отличается только двумя названиями кнопок. Остальная логика `site.js`, конфиг, premium.css, sitemap, robots и Google verification совпадают с базой.

## Воспроизведение

Из корня репозитория, с установленными Playwright и Edge:

```powershell
$env:METRIKA_SDK_PATH='полный путь к неизменённой копии https://mc.yandex.ru/metrika/tag.js'
# При необходимости NODE_PATH указывает на существующий node_modules с Playwright.
node docs/cookie-notice-review/test-browser.cjs
node --check site.js
node --check docs/cookie-notice-review/test-browser.cjs
node tests/test-preflight.mjs
node docs/case-calculator-review/test-engine.mjs
git diff --check
```

Скрипт запускает временный локальный HTTP-сервер и сохраняет протокол/скриншоты в эту папку. SDK в репозиторий не включён. В `browser-results.json` `viewportWidth` — ширина окна, `width` — измеренная ширина панели.
