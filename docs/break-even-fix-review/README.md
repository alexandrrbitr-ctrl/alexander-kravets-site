# Исправление порога лидов — проверка перед draft PR

Проверено 18 октября 2026 года. Ветка `fix-sales-economics-break-even-leads` создана от `feature-site-preflight` / `01dab668e5cdb6cd138ae20208968e0a5203110d`. Это локальная проверка готовящейся версии, а не проверка опубликованного сайта.

## Изменение

Применён `apply_fix.py` из предоставленного архива. До исправления порог лидов выводился из уже округлённого количества целых сделок и составлял 134 лида. Теперь он рассчитывается непосредственно из вклада сделки и ожидаемой конверсии:

`ceil(постоянные расходы / (вклад сделки × конверсия / 100))`.

При стандартных данных вклад сделки равен 24 600 ₽, постоянные расходы — 370 000 ₽. Порог целых заключённых сделок остаётся **16**, порог лидов по ожидаемой конверсии 12% — **126**. Это независимые показатели модели; 126 лидов не гарантируют заключение 16 договоров.

Уточнены подписи и методика в интерфейсе. Дополнительно уточнён копируемый результат: «целых сделок», «лидов по ожидаемой конверсии», пояснение об отсутствии гарантии. В тесты добавлены точные суммы для 125/126 лидов и независимая проверка минимальности порога лидов на 150 моделях. Другие расчёты, подтверждённые результаты кейсов, дизайн, контакты и SEO не менялись.

Сразу после применения пакета повторный запуск установщика показал «УЖЕ ПРИМЕНЕНО» для всех четырёх файлов. Дополнительные тесты и уточнение копируемого текста внесены после этой проверки.

Основные команды:

```sh
node docs/case-calculator-review/test-engine.mjs

node scripts/check-site.mjs
node --check site.js
node --check tools/sales-economics/engine.mjs

```

Для браузерного теста требуется установленный Playwright и Microsoft Edge: `node docs/break-even-fix-review/check-browser.cjs`. При необходимости `NODE_PATH` указывает на существующую установку Playwright. Тест сам запускает временный локальный HTTP-сервер и закрывает его; финансовые данные остаются в браузере. Локальные проверки выполнены на Node v24.19.0. CI на Node 22 проверяется отдельно в PR; его успех не подразумевается локальным прогоном.
