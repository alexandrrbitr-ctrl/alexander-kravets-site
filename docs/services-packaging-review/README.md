# Коммерческая упаковка услуг — проверка

Ветка `feature-services-packaging`, основание — опубликованная `main`, коммит `0789417`.
Изменения предназначены для проверки в отдельной ветке. В `main` не объединены.

## Было → изменили → стало

- Было: шесть направлений в карточках и повторяющихся раскрывающихся списках; выбор требовал знания терминов.
- Изменили: три сценария по задаче клиента и семь направлений в содержательных горизонтальных блоках. Для каждого указаны проблема, состав работы, результат и первый шаг. Построение отдела с нуля выделено как флагман.
- Стало: можно выбрать разовую экспертную задачу, проектирование, внедрение или регулярное сопровождение с понятными границами участия.

Разделены проектирование и организация запуска отдела; коммерческая экспертиза и техническое внедрение CRM; полноценное внешнее управление и еженедельный независимый контроль. Добавлена независимая проверка AI-контроля продаж без обещания разработки AI-систем.

Подтверждённый кейс запуска: пять менеджеров, 33 договора в первый месяц, выполнение плана продаж 134% в первый и 150% во второй месяц. Это результаты комплексного проекта, без обещания их повторения. Ссылки на фарм-кейс и контакт-центр также сопровождаются пояснением масштаба проекта.

## Объём изменений

- `services/index.html` — новая композиция каталога, без создания новых страниц.
- `services/packaging.css` — стили новых блоков на действующих токенах V27; подключены только в каталоге и на главной.
- `index.html` — изменён только раздел коммерческих услуг и добавлено подключение его стилей.
- 15 существующих страниц услуг — точечные уточнения границ внедрения и сопровождения. Для Bitrix24 отдельно указана роль технических специалистов. Изменённые ответы FAQ синхронизированы с JSON-LD.
- Кейсы, изображения, контакты, `site.js`, основные стили V27, архитектура будущих продуктов и sitemap сохранены.
